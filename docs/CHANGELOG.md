# Изменения

## 0.23.1

- Одинарное нажатие на значок трея теперь открывает главное окно. В 0.23.0 оно открывало только панель избранного, оставляя ВанБаз свёрнутым.
- Панель избранного доступна через правую кнопку на значке трея. Двойное нажатие и команда «Открыть ВанБаз» также восстанавливают окно.

## 0.23.0

- Добавлены список сохранённых версий программы и ручной возврат, создание серверной базы, поиск установленных шаблонов, выборочная и грубая очистка кэша нескольких профилей.
- Перенесены интервал автоматических снимков при запуске, предупреждение о повторном запуске, уведомление о старте базы и четыре способа передачи подключения. Добавлена проверка версии работающего локального серверного агента; удалённая версия остаётся неизвестной.
- Появились команды регистрации COM и управления существующими службами 1С с предварительным планом и подтверждением. Установка новой службы остаётся за установщиком 1С.
- Доработаны выбор группы и платформы, создание базы, удаление с необязательным карантином, панель трея, свойства 7.7 и веб-публикаций, дерево настроек, предпросмотр темы и выбор носителя для переносимой копии.
- Замена путей и форматирование имён работают также с отдельным `.v8i`. Перед записью доступны предпросмотр и проверка изменения источника; сохраняется резервный файл.
- Проверка релиза выбранной базы объединяет HTTPS и локальный UpdInfo.txt, поддерживает F5 и переход к дистрибутиву нужной версии. Источник и результат сохраняются отдельной кнопкой.
- В обновлении программы добавлены напоминание через сутки и отменяемый отсчёт необязательной загрузки. Установка требует отдельного подтверждения.
- Ошибки запуска приложения и необработанные ошибки интерфейса показываются в общем окне с подробностями, копированием и ссылкой на GitHub Issues. Фатальное завершение не пересохраняет каталог.
- Импорт `.v8i` исключает распознаваемые поля паролей из локальных записей. Исходные списки при чтении остаются неизменными; ранее сохранённые резервные файлы не переписываются.

## 0.22.0

- Добавлена отдельная системная панель с плитками, перезапуском, выбором монитора и созданием переносимой копии. Перезапуск сохраняет каталог данных и режим интерфейса.
- Расширены команды трея, добавлены кнопка обновления истории, необязательные кнопки запуска в строках, Ctrl+B для меню закладок и Alt+F1 для справки.
- В основных настройках появилась иерархическая навигация. В свойствах базы можно определить сведения о конфигурации, в поиске доступны сравнение размера и верхняя граница даты, в списке конфигураций появились текстовый и страновой фильтры.
- Добавлены запуск установленной MMC-консоли 1С и окно ошибки с подробностями и копированием. Регистрация COM и изменение служб из программы не выполняются.
- Исправлены перехват Shift+Insert в поиске, состояния недоступных кнопок импорта и свойств строк, а также доступность проверки обновлений при пустом результате отбора конфигураций.
- Сохраняются отличия от StartManager: нет ручного выбора прежней версии для отката, создания серверной базы из мастера и дерева установленных шаблонов. Очистка кэша использует собственный механизм карантина; оформление и некоторые формы также различаются.

## 0.21.0

- Добавлена компактная портативная сборка Windows x64. .NET Desktop Runtime 8 устанавливается отдельно по ссылке в инструкции.
- В README появились снимки светлой и тёмной темы, а также окна оформления. Для снимков использованы вымышленные базы.
- Удалён демонстрационный режим. Учебные примеры остались только в средствах подготовки снимков интерфейса и не входят в поставку.
- Переносимая копия теперь включает среду выполнения, если она есть в исходной сборке.

## 0.20.0

Первая публикация исходников ВанБаз. Запуск баз 1С, штатные списки, группы, избранное, профили запуска, история, обслуживание кэша, горячие клавиши и темы.
