# Изменения

## 0.22.0

- Добавлена отдельная системная панель с плитками, перезапуском, выбором монитора и созданием переносимой копии. Перезапуск сохраняет каталог данных и режим интерфейса.
- Расширены команды трея, добавлены кнопка обновления истории, необязательные кнопки запуска в строках, Ctrl+B для меню закладок и Alt+F1 для справки.
- В основных настройках появилась иерархическая навигация. В свойствах базы можно определить сведения о конфигурации, в поиске доступны сравнение размера и верхняя граница даты, в списке конфигураций появились текстовый и страновой фильтры.
- Добавлены запуск установленной MMC-консоли 1С и окно ошибки с подробностями и копированием. Регистрация COM и изменение служб из программы не выполняются.
- Исправлены перехват Shift+Insert в поиске, состояния недоступных кнопок импорта и свойств строк, а также доступность проверки обновлений при пустом результате отбора конфигураций.
- Сохраняются отличия от StartManager: нет ручного выбора прежней версии для отката, создания серверной базы из мастера и дерева установленных шаблонов. Очистка кэша использует собственный механизм карантина; оформление и некоторые формы также различаются.

## 0.21.0

- Добавлена компактная портативная сборка Windows x64. .NET Desktop Runtime 8 устанавливается отдельно по ссылке в инструкции.
- В README появились снимки светлой и тёмной темы, а также окна оформления. Для снимков использованы вымышленные базы.
- Удалён демонстрационный режим. Учебные примеры остались только в средствах подготовки снимков интерфейса и не входят в поставку.
- Переносимая копия теперь включает среду выполнения, если она есть в исходной сборке.

## 0.20.0

Первая публикация исходников ВанБаз. Запуск баз 1С, штатные списки, группы, избранное, профили запуска, история, обслуживание кэша, горячие клавиши и темы.
